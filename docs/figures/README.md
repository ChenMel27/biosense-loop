# Figure status

The PNG and SVG files in this directory document the earlier V1 probe, revision, transfer, and survey workflow. They are retained as historical design artifacts and should not be presented as the current ExitLoop architecture or student flow.

The current product flow is:

1. The teacher reviews one grade-appropriate application task, target ideas, and possible misconceptions.
2. The student writes at least three complete sentences and submits once.
3. ExitLoop classifies the response against the approved content and shows a brief answer-neutral summary.
4. The teacher reviews class patterns and the responses behind them.

Create new figures from the current specifications before the next external presentation.
